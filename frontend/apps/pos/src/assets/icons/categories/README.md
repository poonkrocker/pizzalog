# Pizzalog POS — categoría icons

Este directorio reúne iconos de categoría para el punto de venta móvil. Diseño previsto: pixel art limpio, retícula 32×32, fondo transparente, paleta cálida compatible con ambos temas.

Archivos previstos:
- category-pizza.svg — porción de pizza
- category-drinks.svg — lata
- category-desserts.svg — porción de tiramisú/postre
- category-promos.svg — pizza y lata
- category-starters.svg — pincho/entrada
- category-sandwiches.svg — sándwich
- category-hotdogs.svg — pancho con salchicha visible
- category-coffee.svg — taza de café
- category-extras.svg — billete/extra
- category-hot-meals.svg — plato caliente con vapor
- category-salads.svg — ensaladera
- category-sides.svg — guarnición/papas
- category-breakfast.svg — café y medialuna/tostada
- category-ice-cream.svg — helado
- category-other.svg — plato/cubiertos genéricos
- category-uncategorized.svg — caja genérica para categorías sin asignación

Los assets ilustrativos de categoría serán a color y no deben cambiar según el tema. Los iconos de interfaz/control seguirán siendo SVG lineales tintables con `currentColor`.
